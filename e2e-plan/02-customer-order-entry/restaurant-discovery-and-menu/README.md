# restaurant-discovery-and-menu

Basic menu visibility, customer-role gating, all-item name/price integrity, category headings, home-browser brand/distance coverage, nearby outlet switching, search, no-results, and filter clearing pass. The out-of-stock control check is implemented but currently blocked by the randomly selected outlet having no unavailable item; this data dependency is recorded in `PENDING.md`.

See [scenarios.md](scenarios.md) and [pending work and validation notes](PENDING.md) for evidence and remaining coverage. All actions are through the UI; no checkout or backend access.
