# 02-customer-order-entry

Prepare a customer order using existing data and a serviceable outlet.

Work through one functionality folder at a time:

- [saved-address-and-outlet-selection](saved-address-and-outlet-selection/README.md): Existing Home address, Brand1 outlet dropdown, live distance and rider coverage.
- [restaurant-discovery-and-menu](restaurant-discovery-and-menu/README.md): Restaurant browsing, categories, menus and item availability.
- [cart-and-pricing](cart-and-pricing/README.md): Cart contents, quantities, totals, fees and discounts.
- [checkout-and-payment](checkout-and-payment/README.md): Checkout, payment UI and order creation.
