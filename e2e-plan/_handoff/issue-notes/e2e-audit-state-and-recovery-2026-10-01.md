## Prevention

Use a single explicit owner for shared selection state. Distinguish unknown/loading, successful empty and failed responses. Preserve exact operation/resource IDs through creation and recovery. Begin protected subscriptions only after the prerequisite server command succeeds. Verify error bodies using the actual client envelope, not a guessed shape. Regression tests must fail before a fix and cover delayed success, failure and stale/repeated interactions.

Reusable rules: [frontend standards](../../../../CodingPracticesAcrossAllServices/12_Frontend/ui-standards.md), [realtime standards](../../../../CodingPracticesAcrossAllServices/06_ApiAndIntegration/websocket-and-realtime.md).

Correction772f50d explicitly supplies proxy_pass/HTTP forwarding headers and suppresses the upgrade Connection header for SSE. An isolated loopback-only candidate Nginx process proved both paths reach the gateway's unauthenticated401, then exited without changing the running configuration.
