# reviews-and-support

Status: **not production-ready yet**. On 2026-09-29, customer and restaurant review flows, My Reviews, and the populated restaurant feedback/aggregate passed against the deployed development environment. The deployed rider history endpoint now returns a newly completed order while that rider is Offline, so off-duty read access is healthy. The rider dashboard then exposed a separate frontend crash: its optimistic completed-order entry has no payout until the server calculation is available, and the earnings calculation threw an error. A local UI fix keeps the dashboard usable, reads the existing owner-scoped payout endpoint at most four times after successful delivery, and shows an unavailable state if the payout still cannot be confirmed; deploy it and rerun the existing-order rider review flow before marking participant reviews complete. No backend change is proposed for this crash.

Scope: Ratings, reviews and post-delivery support.

Implementation: `ReviewFlowTest.submitReview` covers customer ratings for the order's restaurant, assigned delivery partner, and purchased dish, plus restaurant and delivery-partner ratings for their permitted order participants. It reopens submitted reviews and checks they are read-only. The rider portion is pending a live rerun after deploying the optimistic-payout dashboard fix. `CustomerSettingsUiTest.myReviewsTabShowsReviewsOrDefinedEmptyState` checks customer review history, while `deliveredOrderReviewRequiresAtLeastOneRating` verifies the shared modal target list and blocks a no-rating submission. `RiderReviewHistoryApiTest` checks authenticated rider history for an existing order without changing duty or review state. `RestaurantNavigationUiTest.restaurantReviewsShowPublicFeedbackAndAggregate` checks both populated and defined-empty public review states and the outlet aggregate. Backend tests cover ineligible actors, targets, and duplicate submissions. See [validation failures and pending work](PENDING.md) for current results and the live-test boundary.
