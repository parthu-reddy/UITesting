# 03-order-fulfillment

Complete the core journey while monitoring customer, restaurant and rider together.

Work through one functionality folder at a time:

- [restaurant-acceptance-and-preparation](restaurant-acceptance-and-preparation/README.md): Restaurant queue, acceptance and kitchen preparation.
- [rider-availability-and-dispatch](rider-availability-and-dispatch/README.md): Rider availability, location, dispatch eligibility and job acceptance.
- [pickup-and-delivery](pickup-and-delivery/README.md): Pickup, handover and delivery completion.
- [customer-tracking-and-history](customer-tracking-and-history/README.md): Active orders, progress, history and reorder.
- [cross-role-order-lifecycle](cross-role-order-lifecycle/README.md): One coordinated customer-to-restaurant-to-rider journey and state agreement.
